# Neural Script New Site

A modern marketing and product landing page for Neural Script, built with Next.js, React, TypeScript, and Tailwind CSS.

## Overview

This project showcases the Neural Script platform with sections for:

- product positioning and feature highlights
- platform metrics and infrastructure details
- integrations and security messaging
- developer-focused content and testimonials
- pricing and conversion-focused call-to-action sections

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn-style UI primitives

## Getting Started

1. Install dependencies:
   pnpm install

2. Start the development server:
   pnpm dev

3. Open the app in your browser:
   http://localhost:3000

## Build for Production

pnpm build

## Notes

This repository is intended for a marketing site and frontend presentation, and it is configured for local development without committing secrets or environment variables.
